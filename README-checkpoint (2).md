# PyBullet Object Tracking Simulation

This module contains the PyBullet-based simulation of the vision-based UAV
object tracking and following system.

## Components

- Drone simulation
- Onboard camera simulation
- Moving target
- Target detection
- PID-based tracking controller
- Camera-centering control
- Distance/altitude control

The main implementation is located in `src/`.
